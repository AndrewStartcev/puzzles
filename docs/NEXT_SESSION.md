# Мир пазлов — следующая сессия

Миграция на web выполнена 2026-09-13. Vite + React + TypeScript + PixiJS/WebGL — основная версия. Предыдущий прототип удалён; assets/puzzles/test.jpeg сохранён.

## Ручное ревью

1. npm ci, npm run dev: главная → сложность → стол.
2. Проверить 12, 300, 1200 и ~3000: форма Classic, отсутствие серой обводки, UV и стыки.
3. Tray, свободный drag, повторное перетаскивание, snap, завершение и фильтр краёв.
4. Wheel, pan, F / fit, pinch и смена размера окна. Большая сложность увеличивает стол.
5. Перезагрузить, продолжить и сравнить seed, позиции, камеру, время, прогресс. Проверить заблокированное хранилище и изменённый ассет.
6. Измерить 3000 деталей на реальном desktop/mobile: холодная генерация, p95 frame time, память, fit с полным столом. Browser smoke не заменяет performance review.

## Развитие

- Утвердить форму Classic и визуальный стиль четырёх базовых экранов.
- Spatial index, LOD / объединённая геометрия по измерениям; группы свободных деталей пока не реализованы.
- Настоящие коллекции и metadata, поиск / фильтры, несколько сохранённых пазлов и настройки.
- Зарегистрировать приложения Пикабу, VK и Одноклассников, проверить init и lifecycle в контейнерах. Уточнить VK Mini Apps / VK Games launch flow.
- Облачное хранение через площадки / backend с conflict resolution, затем авторизация, реклама, покупки; текущие capabilities false.
- После подтверждения ядра: daily, задания, магазин / косметика / экономика.

Яндекс Игры не входят в план; SDK не подключается.
