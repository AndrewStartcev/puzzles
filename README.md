# Мир пазлов

Браузерная игра на **Vite + React + TypeScript + PixiJS 8 / WebGL**. Одна картинка процедурно превращается в пазл на 12–~3000 деталей. Старый Godot-прототип удалён; его история доступна в Git.

## Локальный запуск

Нужен Node.js **22.12+**, рекомендуется Node 22 LTS.

```sh
git clone https://github.com/AndrewStartcev/puzzles.git
cd puzzles
npm ci
npm run dev
```

Открыть адрес dev-server, обычно http://127.0.0.1:5173. SDK для локального режима не нужны.

```sh
npm run check       # тесты ядра + TypeScript + production-сборка
npm run preview     # посмотреть dist локально
npx playwright install chromium
npm run test:e2e    # browser smoke: drag/snap, сохранение, ~3000, адаптив
```

`dist/` — статическая сборка для HTTPS-хостинга / iframe. Относительный Vite base позволяет размещение в подпапке. Обновляйте сборку атомарно; не кэшируйте index.html навечно.

## Реализовано

- Полноэкранное игровое меню на 16:9: светлый деревянный стол, тканевое поле, объёмные кнопки, пазл на столе; отдельная полка коллекций, бумажная карточка выбора сложности, настройки, продолжение и завершение.
- Seed-based геометрия Classic: Bézier-выступы, общие стыки, триангуляция earcut в Web Worker.
- Одна исходная texture, UV на контурах; без нарезки тысяч изображений и серых обводок.
- Drag/snap мышью и pointer events; установленные детали фиксируются.
- Большое поле: деталь шириной 160 мировых единиц, поверхность растёт со сложностью.
- Zoom колесом / кнопками, pan свободного места / ПКМ / СКМ, pinch двумя пальцами, F — весь пазл.
- Одна вертикальная линия деталей справа: виртуализация, фильтр краёв. Отпускание вне поля возвращает деталь назад.
- «Раскидать пазлы» переносит свободные детали на доску вокруг зоны сборки и случайно поворачивает их. Короткий клик поворачивает такую деталь на 90°, drag переносит её; snap требует правильной ориентации. Уже установленные детали не меняются.
- Прозрачность подсказки 0–100%, отдельный полноразмерный макет. Положение, повороты и прозрачность сохраняются; старые сохранения совместимы.
- Нарисованный фон комнаты и независимая доска с деревянной рамой, единые SVG-иконки Phosphor duotone, объёмные светлые кнопки. Служебного footer нет.
- Версионированное локальное сохранение seed, позиций, статусов, камеры и времени; debounce, checkpoint, flush при скрытии / выходе.
- PixiJS meshes создаются только для видимых деталей на столе; общая texture и batching.

Сетка подстраивается под пропорции картинки; точное количество видно в игре, максимум 3000. Для больших пазлов начальный zoom сохраняет удобный размер деталей; обзор всей картины доступен отдельно.

## Платформы

Цели: **Пикабу Игры, VK Mini Apps / игры, Одноклассники**. Яндекс Игры не поддерживаются; SDK и адаптера для них нет.

Выбор: `VITE_PLATFORM=local|pikabu|vk|ok` в `.env.local` или URL `?platform=...`. Переменная окружения имеет приоритет. SDK загружается только для выбранной площадки. При ошибке появляется сообщение и открывается локальный режим.

Адаптеры реализуют официальную инициализацию SDK; Пикабу также получает сигнал готовности. **Сохранения сейчас на устройстве для всех адаптеров**, capabilities cloudSave / ads / payments = false. Облако, реклама, платежи и проверка в реальных контейнерах площадок — следующий этап с зарегистрированными приложениями. Инициализация не означает завершённую платформенную сертификацию; VK Games вне Mini Apps может потребовать отдельный launch flow внутри VK-адаптера.

## Структура

```text
assets/puzzles/           исходные изображения, test.jpeg сохранён без изменений
assets/ui/                отдельные фон / доска и описание происхождения
src/app/                 состояние экранов, bootstrap платформы
src/ui/                  React-каркас и игровая композиция
src/content/             каталог и сложности
src/game/puzzle-core/    чистая модель, геометрия, Worker, snap
src/game/renderer/       PixiJS / WebGL и pointer input
src/game/camera/         математика zoom/pan
src/game/tray/           виртуальный React/SVG tray
src/game/save/           формат и валидация сохранений
src/platform/            local / pikabu / vk / ok
tests/                   ядро и браузерные сценарии
```

PNG/JPG/JPEG/WebP автоматически включаются из assets/puzzles через Vite. Каталог тестовый; магазин / daily / экономика остаются продуктовым планом. Соединение свободных деталей в группы пока не реализовано.
