# Пазлы — Godot 4

Процедурный прототип пазлов: одна исходная картинка автоматически превращается в набор деталей с совместимыми выступами и выемками.

## Быстрый тест

1. Положить картинку в `assets/puzzles/test.webp`.
2. Рекомендуемый размер: **1600 × 1200 px** (4:3).
3. Открыть проект в Godot 4.x.
4. Запустить проект (`F6/F5`).

По умолчанию создаётся пазл **4 × 3 = 12 деталей**.

## Что уже работает

- одна исходная текстура без ручной нарезки;
- процедурная форма деталей;
- соседние выступы и выемки совпадают;
- перетаскивание мышью и touch;
- полупрозрачная подложка исходной картинки;
- защёлкивание детали рядом с правильной позицией;
- счётчик собранных деталей;
- экран завершения;
- `R` — перемешать пазл заново;
- если `test.webp` отсутствует, берётся первый PNG/JPG/JPEG/WebP из `assets/puzzles/`.

## Структура

- `project.godot` — настройки проекта;
- `scenes/main.tscn` — стартовая сцена;
- `scripts/main.gd` — генератор пазла и игровая логика;
- `scripts/puzzle_piece.gd` — отдельная перетаскиваемая деталь;
- `assets/puzzles/` — исходные картинки.

## Принцип генерации

Каждая деталь — это `Polygon2D`, который использует исходную картинку как общую текстуру. Генератор строит контур детали и соответствующие UV-координаты, поэтому отдельные изображения деталей заранее создавать не нужно.
