# Мир пазлов

HTML5 puzzle-hub с процедурной генерацией деталей: одна исходная картинка автоматически превращается в пазл нужной сложности без ручной нарезки ассетов.

## Текущий статус

В репозитории сейчас находится рабочий **Godot 4 прототип**, на котором проверены:

- процедурная форма деталей;
- совместимые соседние выступы/выемки;
- текстурирование деталей исходной картинкой;
- drag & snap;
- режимы разного количества деталей;
- zoom/pan для большого игрового поля.

Godot-прототип сохраняем как технический референс.

**Production-версию «Мир пазлов» планируем делать как web SPA:**

- Vite;
- React;
- TypeScript;
- PixiJS / WebGL;
- SCSS/CSS;
- отдельные platform adapters для Яндекс Игр и Пикабу.

## Godot-прототип — быстрый тест

1. Положить картинку в `assets/puzzles/`.
2. Рекомендуемый тестовый размер: **1600 × 1200 px** (4:3).
3. Открыть проект в Godot 4.x.
4. Запустить проект (`F6/F5`).

Поддерживаются PNG/JPG/JPEG/WebP.

## Ключевой production-принцип

Изображение хранится один раз. Геометрия деталей создаётся процедурно, поэтому добавление нового пазла в будущем должно сводиться в основном к добавлению картинки и metadata.

Для больших режимов 1000–3000 деталей увеличивается рабочая поверхность и используется zoom/pan — сами детали не должны становиться микроскопическими только ради размещения всего пазла на одном экране.
