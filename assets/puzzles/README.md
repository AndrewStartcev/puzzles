# Изображения пазлов

`test.jpeg` — исходный тестовый ассет, сохранён без изменения байтов.

Добавляйте PNG, JPG, JPEG, WebP сюда или в тематические подпапки. Vite включает изображения через src/content/catalog.ts. После добавления перезапустите dev-server. Metadata / названия коллекций расширяйте в каталоге отдельно.

Рекомендуется 1600 × 1200 или больше при разумном размере файла. Пропорции считываются автоматически, сетка и UV рассчитываются из картинки. Ручная нарезка не нужна.
