# Картинки для пазлов

Для первого теста положи сюда файл:

`test.webp`

Полный путь в проекте:

`res://assets/puzzles/test.webp`

Рекомендуемый размер: **1600 × 1200 px** (4:3).

Поддерживаются: WebP, PNG, JPG, JPEG.

Если `test.webp` отсутствует, игра попробует взять первый подходящий файл из этой папки.
